# LifeTracker v0.3 — Новые возможности

## 🎯 Система уровней и опыта

### Прогрессия опыта
- **Настраиваемая сложность**: формула прогрессии задается в `DEFAULT_LEVELING_CONFIG`
  - `baseXP`: 100 (базовый опыт для уровня 1)
  - `growthFactor`: 1.8 (коэффициент роста — тяжелая прогрессия)
  - `formula`: 'quadratic' (линейная, квадратичная, экспоненциальная)

### XP за действия
```javascript
const XP_REWARDS = {
  habit: 10,      // За выполнение привычки
  task: 20,       // За выполнение задачи
  idea: 20,       // За реализацию идеи
  goalBase: 40    // За цель (умножается на дни)
};
```

### Уровни игрока (50 уровней)
От "Неофита" до "Императора" с самурайской тематикой:
- Уровень 0: Неофит
- Уровень 12: Самурай
- Уровень 40: Дзен-мастер
- Уровень 50: Император

## 📜 Титулы характеристик

Для каждой из 6 характеристик (ИНТ, СИЛ, ВЫН, ХАР, ЗД, ЭН) создано по 50 уникальных титулов:

### Примеры титулов:
**ИНТ (Интеллект)**:
- 0: Наблюдатель → 20: Визионер → 40: Повелитель истин → 50: Абсолютная мудрость

**СИЛ (Сила)**:
- 0: Слабый → 12: Самурай → 25: Геракл → 50: Абсолютное превосходство

**ВЫН (Выносливость)**:
- 0: Истощённый → 20: Марафонец → 40: Божественное терпение → 50: Абсолютное бессмертие

**ХАР (Харизма)**:
- 0: Незаметный → 20: Магнетический → 40: Император харизмы → 50: Всемогущество влияния

**ЗД (Здоровье)**:
- 0: Болезненный → 20: Биохакер → 40: Император бессмертия → 50: Абсолютное бессмертие

**ЭН (Энергия)**:
- 0: Истощённый → 20: Молниеносный → 40: Всемогущество мотивации → 50: Абсолют

## 🏆 Система наград

### Типы наград
```javascript
const REWARD_TYPES = {
  ACCESSORY: 'accessory',  // Реальный аксессуар (часы, кольцо, браслет)
  DECOR: 'decor',          // Декор для дома (статуэтка, картина, грамота)
  TITLE: 'title',          // Титул/Эпитет
  ACCESS: 'access'         // Доступ к испытаниям
};
```

### Структура данных (`rewards.json`)
```json
{
  "currency": 0,           // Очки славы (валюта за уровни)
  "inventory": [],         // Разблокированные награды
  "slots": {
    "accessory": null,     // Текущий носимый аксессуар
    "decor": null          // Текущий декор
  },
  "titles": [],            // Разблокированные титулы характеристик
  "accesses": []           // Разблокированные доступы к испытаниям
}
```

### Функционал
- **Очки славы**: валюта, получаемая за повышение уровня
- **Инвентарь**: хранит все разблокированные награды
- **Слоты экипировки**: аксессуар и декор для отображения
- **Титулы характеристик**: автоматически присваиваются при росте статов

## ⚔️ Испытания (в разработке)

### Концепция
- Дела и идеи с минимальным порогом характеристики
- Порог становится read-only после первой редакции
- Требуется пересоздание для изменения порога

### Пример использования
```javascript
// Дело с требованием СИЛЫ >= 30
{
  id: 'wi_hard',
  kind: 'task',
  name: 'Поднять камень',
  minStat: { key: 'strength', value: 30 }, // Read-only после создания
  status: 'backlog'
}
```

## 📊 Интерфейс

### Dashboard Modal
- Карточка уровня с прогресс-баром XP
- Кнопка "🏆 Награды и титулы" → открывает RewardsModal

### Rewards Modal
- Уровень и общий XP игрока
- Титулы всех 6 характеристик
- Очки славы (валюта)
- Инвентарь наград
- Активные слоты (аксессуар, декор)
- Тестовая кнопка добавления награды

## 🔧 Технические детали

### Файлы данных
- `LifeTracker/reference.json` — справочники
- `LifeTracker/workItems.json` — дела и идеи
- `LifeTracker/journal/*.json` — ежедневные записи
- `LifeTracker/rewards.json` — **новый файл** с данными наград

### Основные функции
```javascript
// Расчет требуемого опыта
xpRequiredForLevel(level, config)

// Получение текущего уровня
getPlayerLevel(totalXP, config)

// Получение титула характеристики
getStatTitle(statKey, statValue)

// Расчет общего XP
calculateTotalXP(store, journalData)
```

## 🎮 Как использовать

1. **Выполняйте действия**: привычки, задачи, идеи, цели
2. **Получайте XP**: автоматически начисляется за выполнение
3. **Повышайте уровень**: достигайте порогов XP
4. **Растите характеристики**: выполняйте действия с эффектами
5. **Получайте титулы**: автоматически присваиваются по значению стата
6. **Копите очки славы**: за каждый новый уровень
7. **Тратьте на награды**: аксессуары, декор, титулы, доступы
