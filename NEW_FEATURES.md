# 🎮 LifeTracker: Система уровней, опыта и наград

## ✨ Новые возможности (v0.3)

### 1. Система уровней игрока с настраиваемой прогрессией

**50 уровней** от "Неофита" до "Императора" с самурайской тематикой:
- Неофит → Искатель → Ученик → Подмастерье → Кэнси → ... → Дзен-мастер → ... → Император

**Настраиваемая формула прогрессии** (`DEFAULT_LEVELING_CONFIG`):
```javascript
{
  baseXP: 150,          // Базовый опыт для уровня 1
  growthFactor: 2.0,    // Коэффициент роста (тяжелая прогрессия)
  formula: 'quadratic', // 'linear', 'quadratic', 'exponential'
  gloryPerLevel: 50     // Очки славы за каждый уровень
}
```

**Начисление XP:**
- Привычка выполнена: **10 XP**
- Задача/Идея выполнена: **20 XP**
- Цель завершена: **40 XP × количество дней**

### 2. Уникальные титулы для каждой характеристики

Для каждой из 6 характеристик (ИНТ, СИЛ, ВЫН, ХАР, ЗД, ЭН) — **50 уникальных титулов**:

**Примеры:**
- **ИНТ**: Наблюдатель → Любопытный → ... → Мудрец → ... → Император интеллекта → Абсолютная мудрость
- **СИЛ**: Слабый → Хрупкий → ... → Самсон → ... → Владыка мощи → Абсолютное превосходство
- **ХАР**: Незаметный → Тихий → ... → Лидер → ... → Император харизмы → Всемогущество влияния
- **ЗД**: Болезненный → Слабый → ... → Хранитель здоровья → ... → Император бессмертия
- **ВЫН**: Истощённый → Утомлённый → ... → Неостановимый → ... → Абсолютная выносливость
- **ЭН**: Истощённый → Пустой → ... → Космический поток → ... → Всемогущество мотивации

Титул отображается в окне наград и зависит от текущего значения характеристики (0-50+).

### 3. Система наград

**Файл данных:** `LifeTracker/rewards.json`

**Типы наград:**
1. **📿 Аксессуар** — реальный предмет для ношения (часы, кольцо, браслет)
2. **🏺 Декор** — украшение для дома (статуэтка, картина, грамота)
3. **📜 Титул/Эпитет** — качественное изменение восприятия себя
4. **🔓 Доступ** — право участвовать в испытаниях

**Валюта:** Очки славы (🪙)
- Начисляются автоматически при повышении уровня (50 за уровень)
- Можно добавлять пользовательские награды через интерфейс

**Инвентарь и слоты:**
- Все разблокированные награды хранятся в инвентаре
- Можно экипировать: 1 аксессуар + 1 декор
- Экипированные предметы отображаются в профиле

**Интерфейс наград** (кнопка "🏆 Награды и титулы" на дашборде):
- Текущий уровень и прогресс XP
- Титулы всех характеристик
- Баланс очков славы
- Инвентарь с кнопками "Экипировать"/"Снять"
- Форма добавления пользовательских наград

### 4. Испытания с требованиями характеристик

**Механика:**
- При создании задачи/идеи можно установить минимальный порог характеристики
- Пример: "СИЛА >= 30" для доступа к испытанию
- После первого сохранения требование становится **read-only** (нельзя изменить)
- Для изменения нужно пересоздать задачу/идею

**Визуализация:**
- Задачи без требования: 📝 или 💡
- Задачи с невыполненным требованием: 🔒 (заблокированы, полупрозрачные)
- Отображение текущего и требуемого значения: "(СИЛ 25/30)"

**Где используется:**
- Модальное окно "Дела и идеи" — показывает доступность
- Редактор задачи/идеи — настройка требования (только для новых)

### 5. Автоматическое начисление наград

При открытии окна наград система:
1. Проверяет текущий уровень игрока
2. Сравнивает с `lastProcessedLevel`
3. За каждый новый уровень:
   - Начисляет очки славы (50 × количество уровней)
   - Добавляет награду "Награда за уровень N" в инвентарь
4. Обновляет `lastProcessedLevel`
5. Показывает уведомление о получении

## 🎯 Как использовать

### 1. Повышение уровня
- Выполняйте привычки, задачи, идеи и цели
- Откройте дашборд — увидите прогресс XP
- При повышении уровня получите очки славы

### 2. Просмотр титулов
- Откройте "🏆 Награды и титулы"
- Посмотрите текущие титулы характеристик
- Титулы обновляются автоматически при росте статов

### 3. Добавление наград
- В окне наград нажмите "➕ Добавить награду"
- Введите название, выберите тип
- Награда появится в инвентаре

### 4. Экипировка предметов
- В инвентаре нажмите "Экипировать" на предмете
- Предмет займёт соответствующий слот
- Чтобы снять — нажмите "Снять"

### 5. Создание испытаний
- Откройте "📋 Дела и идеи"
- Создайте новую задачу/идею
- Установите требование к характеристике
- Сохраните (после этого нельзя изменить!)

## 🔧 Технические детали

### Функции
- `xpRequiredForLevel(level, config)` — расчёт порога уровня
- `getPlayerLevel(totalXP, config)` — получение текущего уровня
- `getStatTitle(statKey, statValue)` — титул характеристики
- `calculateTotalXP(store, journalData)` — общий XP
- `computeTotalXP(store)` — асинхронный подсчёт XP
- `checkAndGrantLevelRewards(store)` — проверка и начисление наград
- `checkStatRequirement(item, currentStats)` — проверка доступа к испытанию

### Хранение данных
- Все данные локальны в JSON-файлах
- Автосохранение после каждого изменения
- Миграция старых структур при обновлении

### Совместимость
- ✅ Работает офлайн
- ✅ Без внешних зависимостей
- ✅ Совместимо с iOS Obsidian
- ✅ Нет запросов к внешним API
