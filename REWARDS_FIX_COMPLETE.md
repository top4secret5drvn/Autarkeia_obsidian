# Исправления системы наград

## Проблема
1. Трофеи не сохранялись в `rewards.json`
2. Настройки прогрессии (сложность уровней) не применялись при пересчёте
3. Отсутствовало описание у трофеев

## Решение

### 1. Исправлено сохранение трофеев
**Файл:** `main.js`

- **Миграция данных** (строки 378-406, 429-462):
  - Добавлена проверка массива `inventory` (инвентарь трофеев)
  - Добавлена проверка массива `slots` (слоты для трофеев)
  - Добавлена проверка числового типа `currency` (очки славы)
  - Добавлена проверка числового типа `unlockedSlots` (разблокированные слоты)
  - Созданы дефолтные данные если файл не существует

- **Создание трофея** (строки 1305-1327):
  - Трофей сохраняется с полями: `id`, `type`, `name`, `description`, `unlockedAt`
  - Описание трофея теперь отображается в инвентаре (строки 1240-1242)
  - После создания трофея данные сразу сохраняются через `saveRewards()`

### 2. Исправлен пересчёт уровней при изменении сложности
**Файл:** `main.js`

- **Функция `getPlayerProgress`** (строки 593-598):
  - Теперь использует сохранённую конфигурацию из `store.rewardsData.levelingConfig`
  - Передаёт конфиг в `getPlayerLevel()` для правильного расчёта

- **Настройки прогрессии в дашборде** (строки 1397-1413):
  - При применении настроек вызывается `checkAndGrantLevelRewards()`
  - Уровень пересчитывается с новыми параметрами формулы
  - Награды начисляются корректно с учётом новой сложности

### 3. Добавлено описание трофеев
**Файл:** `main.js`

- Поле `description` добавлено в структуру трофея (строка 1319)
- Форма создания включает поле для описания (строка 1300)
- Описание отображается в инвентаре под названием трофея (строки 1240-1242)

## Структура данных rewards.json

```json
{
  "currency": 5,                    // Очки славы
  "inventory": [                    // Разблокированные трофеи
    {
      "id": "trophy_1234567890",
      "type": "accessory",          // или "decor"
      "name": "Золотые часы",
      "description": "Подарок за достижение",
      "unlockedAt": "2024-01-15"
    }
  ],
  "slots": [                        // Экипированные трофеи
    {
      "id": "slot_1234567890",
      "trophyId": "trophy_1234567890",
      "trophyName": "Золотые часы",
      "type": "accessory"
    }
  ],
  "unlockedSlots": 3,               // Количество разблокированных слотов (= уровень)
  "lastProcessedLevel": 5,          // Последний обработанный уровень
  "levelingConfig": {               // Настройки прогрессии
    "formula": "quadratic",         // linear/quadratic/exponential
    "baseXP": 100,                  // Базовый опыт
    "growthFactor": 1.5,            // Коэффициент роста
    "gloryPerLevel": 1              // Очков славы за уровень
  }
}
```

## Механика работы

### Начисление наград
- За каждый уровень: **1 очко славы** + **1 разблокированный слот**
- Формула: `lastProcessedLevel + 1 → currentLevel`
- Награды начисляются при открытии модального окна наград

### Создание трофеев
- Стоимость: **1 очко славы** за трофей
- Типы: аксессуар (📿) или декор (🏺)
- Описание: опционально, отображается в инвентаре

### Экипировка трофеев
- 1 слот = 1 экипированный трофей
- Количество слотов = текущий уровень игрока
- Можно надевать/снимать трофеи в окне наград

### Настройка сложности
- **Линейная**: легко, быстрый прогресс
- **Квадратичная**: средне, баланс (по умолчанию)
- **Экспоненциальная**: сложно, медленный прогресс
- Применяется немедленно с пересчётом уровня
