# Исправления системы наград

## Что было исправлено

### 1. Сохранение настроек прогрессии
**Проблема:** Настройки сложности уровней (формула, базовый XP, коэффициент роста) не сохранялись и сбрасывались при перезагрузке.

**Решение:**
- Добавлено поле `levelingConfig` в структуру `DEFAULT_REWARDS_DATA`
- Конфигурация теперь сохраняется в файле `rewards.json`
- При загрузке данных применяется миграция для добавления `levelingConfig` если его нет
- Функция `checkAndGrantLevelRewards()` использует сохранённую конфигурацию вместо дефолтной
- Интерфейс настроек прогрессии отображает и сохраняет актуальные значения

### 2. Создание и сохранение трофеев
**Проблема:** Трофеи не создавались или не сохранялись корректно.

**Решение:**
- Добавлено поле `description` к структуре трофеев в инвентаре
- Форма создания трофея теперь включает поле для описания
- Описание отображается в списке инвентаря трофеев
- Добавлен CSS-класс `.lt-description` для стилизации описания

### 3. Механика наград за уровни
**Реализовано:**
- За каждый уровень даётся **1 очко славы** (настраиваемо)
- За каждый уровень разблокируется **1 слот** для трофеев
- Очки славы можно потратить на создание трофея (1 🪙 = 1 трофей)
- В один слот можно поместить один трофей
- Типы трофеев: аксессуары (📿) и декор (🏺)

## Структура данных

```javascript
{
  currency: 0,                    // Очки славы
  inventory: [],                  // Трофеи: {id, type, name, description, unlockedAt}
  slots: [],                      // Слоты: {id, trophyId, trophyName, type}
  titles: [],                     // Титулы характеристик
  accesses: [],                   // Доступы к испытаниям
  lastProcessedLevel: 0,          // Последний обработанный уровень
  unlockedSlots: 0,               // Количество разблокированных слотов
  levelingConfig: {               // Конфигурация прогрессии
    baseXP: 100,
    growthFactor: 1.5,
    formula: 'quadratic',
    gloryPerLevel: 1
  }
}
```

## Использование

1. **Настройка прогрессии:** В дашборде есть секция "⚙️ Настройки прогрессии"
   - Формула: линейная/квадратичная/экспоненциальная
   - Базовый XP: количество опыта для уровня 1
   - Коэффициент роста: скорость увеличения сложности
   - Очков славы за уровень: сколько 🪙 давать за каждый уровень

2. **Создание трофея:**
   - Откройте "🏆 Награды и титулы"
   - Введите название реального предмета
   - Добавьте описание (необязательно)
   - Выберите тип: аксессуар или декор
   - Нажмите "Создать трофей" (стоит 1 🪙)

3. **Экипировка трофея:**
   - В инвентаре нажмите "Надеть" на трофее
   - Требуется свободный слот (разблокируются с уровнями)
   - Экипированный трофей отображается в секции "🎯 Слоты для трофеев"
